# Rust والجسور الأصلية

- Rust يملك السياسة والتحقق القابلين للمشاركة؛ Swift/Kotlin يملكان الوصول لقدرات النظام. توحيد الواجهة لا يفرض إعادة كتابة ImageIO أو MediaCodec.
- لا `unwrap`/panic على مدخلات الملفات. افحص overflow والأبعاد وعدد العناصر وعمق المراجع قبل الحجز، وحدّ الذاكرة والتزامن. التقاط الاستثناءات لا يعالج OOM أو انهيار native process.
- احصر `unsafe` وموارد FFI، واشرح `SAFETY` والملكية والتحرير والإلغاء. اختبر نهاية العمر عند الفشل كذلك.
- لا تكتب container عامًّا جديدًا لتجنب اعتمادية دون مقارنة تكلفة الصيانة والتوافق. أي كتابة offsets تحتاج تحققًا مستقلًا من المحتوى والعلاقات.
- FRB runtime وcodegen متطابقان (`2.12.0` حاليًا). أعد التوليد عند تغيير API؛ لا تعدّل `frb_generated` أو Dart المولد يدويًا.
- راجع `native/darklib/CONTRIBUTING.md` و`docs/BUILD.md` و`docs/SUPPORT.md` داخل المكتبة. لا تضف nightly أو ABI جديدًا ضمن إصلاح جانبي.
- `rust-version = 1.79` الحالي ادعاء غير مثبت مع القفل الحالي: `image 0.25.10` يطلب 1.88. لا تعلن دعم MSRV حتى يُثبت على ذلك الإصدار.
- قبل إضافة backend: قِس فرق حجم الحزمة المثبتة لكل ABI، زمن البناء، الذاكرة، زمن التشغيل والجودة، وحدد codec المكرر الذي سيزال. لا تخلط حجم مجلدات build بحجم ما يشحن للمستخدم.
