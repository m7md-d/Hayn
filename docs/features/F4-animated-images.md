# F4 — الصور المتحركة (Animated Images)

> المرجع لاختيار الصيغة: `03-FORMATS.md`.

## المصادر
1. **من فيديو:** تحديد نقطة بداية/نهاية أو المقطع كامل.
2. **من مجموعة صور:** ترتيب الإطارات يدويًا.

## التحكّم
- **fps / السرعة:** يحدّد سلاسة ومدّة الناتج.
- **الأبعاد:** تحجيم (lanczos للجودة).
- **التكرار (loop):** لا نهائي افتراضيًا.

## الصيغ
| الصيغة | الأداة | متى |
|---|---|---|
| **WebP متحرك** | libwebp (FFmpeg) | **الافتراضي المقترح** — متوازن، أصغر من GIF، يدعم ألفا |
| **AVIF متحرك** | `flutter_avif` | خيار «أعلى كفاءة» (أبطأ) — حجم صغير جدًا وجودة عالية |
| **GIF** | FFmpeg (palette) | للتوافقية مع المنصّات التي لا تدعم WebP/AVIF |

## قاعدة جودة GIF (إلزامية)
لا تولّد GIF بمسار واحد — استخدم لوحة ألوان لتفادي الـ banding:
```
ffmpeg -i in.mp4 -vf "fps=15,scale=480:-1:flags=lanczos,palettegen" palette.png
ffmpeg -i in.mp4 -i palette.png -lavfi "fps=15,scale=480:-1:flags=lanczos[x];[x][1:v]paletteuse" out.gif
```

## من فيديو إلى متحرك (مثال WebP)
- استخرج النطاق المطلوب (`-ss`/`-t`) ثم رمّز إلى الصيغة المختارة بالـ fps/الأبعاد المحدّدة.
- لـ AVIF المتحرك: جهّز الإطارات ثم `flutter_avif` للترميز.

## من صور إلى متحرك
- رتّب الإطارات + `-framerate <n>` للتحكّم بالسرعة، ثم الصيغة الهدف.
- احترم الشفافية إن وُجدت (لا GIF يفقد ألفا الناعمة — فضّل WebP/AVIF).

## واجهة
- معاينة حيّة للنتيجة + الحجم المتوقّع + شريط بداية/نهاية للفيديو.
- كل عملية = task مع تقدّم/إلغاء.
