# 09 — خريطة الشاشات (Screens & Flows)

> جرد كامل لكل شاشة: الغرض، التخطيط، الأفعال، والحالات. مبني على `07` و`08`.

## خريطة التنقّل العليا
```
Tab Bar:  [ المكتبة ]  [ الأدوات ]  [ المهام ]  [ الإعدادات ]
```
معظم العمليات تبدأ من المكتبة (اختيار أصل) أو من الأدوات (اختيار عملية ثم أصل).

---

## 1. المكتبة (Library)
- **الغرض:** تصفّح ميديا الجهاز.
- **التخطيط:** large-title «المكتبة» + مبدّل (الكل/صور/فيديو) + شبكة 3 أعمدة بمصغّرات + شريط ألبومات أفقي أعلى أو ورقة ألبومات.
- **الأفعال:** فتح أصل (Hero)، ضغط مطوّل → تحديد متعدّد → شريط أدوات سفلي (ضغط/تحويل/جراحي/حذف ميتاداتا…).
- **الحالات:** تحميل (skeleton)، فارغة (لا وسائط/لا إذن مع زر منح)، رفض إذن.

## 2. تفاصيل الأصل (Asset Detail)
- **الغرض:** معاينة + نقطة انطلاق العمليات.
- **التخطيط:** معاينة كاملة (zoom/pan)، شريط معلومات (الأبعاد، الحجم، الصيغة، التاريخ، GPS إن وُجد)، شريط أفعال سفلي.
- **الأفعال:** ضغط/تحويل، قص، حذف ميتاداتا، استبدال جراحي، (فيديو: تحرير/حذف صوت/فصل/استخراج فريمات/تحويل لمتحرك).

## 3. الأدوات (Tools Hub)
- **الغرض:** دخول حسب العملية بدل الأصل.
- **التخطيط:** شبكة بطاقات أفعال مجمّعة: صور (ضغط، قص، حذف ميتاداتا، جراحي) / فيديو (قص، قص حواف، ضغط، حذف صوت، فصل موسيقى) / متحرك (من فيديو، من صور) / استخراج فريمات.
- **التدفّق:** اختيار أداة → اختيار أصل/أصول → شاشة إعداد العملية.

## 4. ضغط/تحويل صورة (Image Compress)
- **التخطيط:** معاينة + Segmented (تلقائي/متقدّم). التلقائي يعرض الصيغة المختارة سببها. المتقدّم: صيغة، جودة (slider مع حجم متوقّع حيّ)، حفظ/حذف ميتاداتا.
- **الفعل:** «ضغط» → task. ملخّص الحجم قبل/بعد.

## 5. القص (Crop)
- واجهة قص native (نِسب + حرّ + تدوير) + تطبيق سياسة الصيغة بعدها.

## 6. ساحة المقارنة الجراحية (Surgical Arena) ⚠️ — أهم شاشة
- **الغرض:** الثقة قبل أي استبدال.
- **التخطيط:** Comparison Slider (قبل/بعد) + تكبير متزامن + شريط إحصاء (الحجم قبل/بعد، التوفير بـ success، قائمة ✓ ميتاداتا/تاريخ/GPS محفوظة).
- **iOS:** شارة المسار (تعديل في المكان / حذف وإنشاء) + تلميح «المضافة حديثًا».
- **الأفعال:** «تأكيد الاستبدال» (destructive، مع ذكر سلة المحذوفات) / إلغاء. هابتكس نجاح عند الاكتمال.
- **الدفعي:** شريط تقدّم كلّي + قائمة نتائج + ملخّص توفير + أي إخفاقات (مع طمأنة سلامة الأصل).

## 7. تحرير الفيديو (Video Editor)
- **التخطيط:** مشغّل + شريط زمني (timeline) بمقابض بداية/نهاية + مؤشّرات keyframe (لتوضيح lossless مقابل smart cut) + أدوات (قص، قص حواف، ضغط).
- **القص:** سحب المقابض؛ مؤشّر يوضّح إن كان القص lossless أو يتطلّب smart cut.
- **قص الحواف:** إطار قص فوق المعاينة + تنبيه «يتطلّب إعادة ترميز مرّة واحدة».
- **الفعل:** «تصدير» → خيارات صيغة/جودة → task.

## 8. حذف الصوت (Mute) — سريع
- تأكيد بسيط «إزالة الصوت (بلا فقدان جودة الفيديو)» → task فوري تقريبًا.

## 9. الصورة المتحركة (Animate)
- **من فيديو:** مقابض بداية/نهاية + fps/سرعة + أبعاد + Segmented صيغة (WebP افتراضي / AVIF أعلى كفاءة / GIF توافقية) + معاينة حيّة + حجم متوقّع.
- **من صور:** ترتيب إطارات (سحب) + fps + نفس خيارات الصيغة.

## 10. استخراج الفريمات (Extract Frames)
- اختيار طريقة (كل N ثانية / fps / لقطة عند المؤشّر) + معاينة شبكة الفريمات الناتجة + حفظ.

## 11. فصل الموسيقى/الآلات (Audio Separation) ⚠️
- **التخطيط:** معاينة المقطع + Strength Slider (تلقائي مميّز) + الوقت المتوقّع الحيّ + بطاقة نصيحة + ملاحظة «أوفلاين، قد يأخذ دقائق».
- **الفعل:** «بدء الفصل» → task خلفي (foreground service) + تقدّم بمراحل (استخراج/فصل/دمج). نتيجة: معاينة قبل/بعد سمعية + حفظ.

## 12. المهام (Tasks)
- قائمة Task Rows (جارية/مكتملة/فاشلة) + تقدّم + إلغاء + ملخّصات + «عرض الناتج». مسح المكتملة.

## 13. سلة المحذوفات (Trash)
- عناصر مع عدّاد حذف نهائي + استعادة + «إفراغ». خاص بالعمليات الجراحية.

## 14. الإعدادات (Settings)
- المظهر (نظام/فاتح/داكن)، اللغة (ar/en)، شكل الأرقام، الجودة/الصيغة الافتراضية، مدّة الاحتفاظ بالمحذوفات، (iOS) المسار الجراحي الافتراضي، «حول» + **تبرّع** (هادئ، لا يفتح ميزات)، إشعار الخصوصية «يعمل أوفلاين بالكامل».

---

## مبادئ التدفّق
- كل عملية ثقيلة → task (لا تجميد) + إمكانية مغادرة الشاشة والمتابعة من «المهام».
- كل فعل مدمّر → تأكيد + تراجع.
- الافتراضي دائمًا «تلقائي» ذكي؛ «متقدّم» مطويّ بلطف.
- كل شاشة: داكن/فاتح × ar/en + حالات تحميل/فارغة/خطأ.
