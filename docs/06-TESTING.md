# 06 — الاختبارات (Testing)

> لكل مرحلة حالات اختبار محدّدة. الميزة الجراحية وفصل الصوت لهما أعلى صرامة.

## مستويات الاختبار
- **Unit**: المنطق النقي (سياسات الصيغ، حسابات الحجم، نقل الميتاداتا).
- **Integration**: المحرّكات (FFmpeg/native/ONNX) على ملفات حقيقية.
- **Golden/UI**: شاشات في الوضعين (داكن/فاتح) واللغتين (RTL/LTR).
- **Stress/Soak**: دفعات طويلة + قطع/إلغاء أثناء العمل.

## عيّنات اختبار إلزامية (Test Corpus)
احتفظ بمجموعة ثابتة تشمل: HEIC من iPhone، JPEG كبير، PNG بشفافية، صورة HDR/10-bit، فيديو H.264، فيديو HEVC، فيديو HDR، فيديو بمعدّل إطارات متغيّر (VFR)، فيديو طويل (>10 دقائق)، Live Photo، صورة بـ GPS+EXIF غني، صوت كلام-فوق-موسيقى.

---

## حالات الاختبار حسب المرحلة

### المرحلة 0 — الأساس
- [ ] تبديل اللغة فوري؛ التخطيط ينعكس صحيحًا في RTL (هوامش، أيقونات، محاذاة).
- [ ] تبديل الثيم فوري؛ تباين AA في الوضعين.
- [ ] مهمة وهمية: تقدّم 0→1، إلغاء ينظّف الموارد.

### المرحلة 1 — المتصفّح
- [ ] رفض الصلاحية ثم منحها يعمل دون كراش.
- [ ] تمرير 5000+ أصل دون لاج ملحوظ.
- [ ] عرض HEIC من iPhone بنجاح على Android.

### المرحلة 2 — الصور [F1]
- [ ] PNG بشفافية لا يتحوّل أبدًا لـ JPEG (يبقى ألفا في AVIF/HEIC/WebP/PNG).
- [ ] كل فرع من شجرة الصيغ يُنتج ملفًا صالحًا أصغر من الأصل.
- [ ] الميتاداتا تُحفظ افتراضيًا؛ وتُحذف بالكامل عند طلب الحذف (تحقّق بقارئ EXIF).
- [ ] صورة 10-bit لا تفقد العمق عند صيغة تدعمه.
- [ ] على جهاز بلا عتاد HEIC: المسار يسقط بأمان إلى WebP.

### المرحلة 3 — FFmpeg/صوت/متحرك
- [ ] حذف الصوت: تيار الفيديو الناتج **مطابق بت-للبت** للأصل (تحقّق بـ hash للـ video stream).
- [ ] GIF بلا banding واضح (مسار palettegen/paletteuse).
- [ ] WebP وAVIF متحرك يعملان ويُعرضان.
- [ ] تغيير fps/السرعة ينعكس بدقّة على المدّة الناتجة.
- [ ] استخراج فريم عند طابع زمني محدّد = الإطار الصحيح.

### المرحلة 4 — تحرير الفيديو [F3]
- [ ] قص lossless عند keyframe: لا إعادة ترميز، الحجم/الجودة محفوظان.
- [ ] smart cut: نقطة القص تطابق الإطار المطلوب (±0)، والحجم لا يتضخّم بلا مبرّر.
- [ ] قص الحواف: الناتج يُفتح ويُشارك في تطبيقات/منصّات أخرى دون كسر (لا اعتماد على crop/display metadata).
- [ ] إعادة الترميز تحدث **مرّة واحدة** فقط (لا تشفير مزدوج).
- [ ] VFR يُعالَج دون انزياح صوت/صورة (sync).

### المرحلة 5 — الجراحية [F2] ⚠️ (أعلى صرامة)
- [ ] **لا حذف قبل تحقّق:** محاكاة فشل التحقّق → الأصل يبقى سليمًا، لا استبدال.
- [ ] **قطع أثناء العملية** (kill/تعطّل/نفاد بطارية محاكى) في كل خطوة → الأصل سليم أو قابل للاستعادة عبر الـ journal.
- [ ] الاسم محفوظ، تاريخ الالتقاط/التعديل محفوظ، الـ GPS والـ EXIF منقولة.
- [ ] **ترتيب الألبوم محفوظ** (Android: نفس الـ ID؛ iOS: الخط الزمني صحيح عبر DateTimeOriginal).
- [ ] iOS: المساران موثّقان وسلوك «المضافة حديثًا» مطابق للمتوقّع في كل مسار.
- [ ] التراجع من سلة المحذوفات يستعيد الأصل بايت-ببايت.
- [ ] الوضع الدفعي يتوقّف/يهدأ عند تجاوز حدّ الحرارة/البطارية.
- [ ] **اختبار إجهاد:** 500+ صورة دفعة واحدة → صفر فقدان، صفر فساد.

### المرحلة 6 — فصل الصوت [F5] ⚠️
- [ ] **لا طقطقة** عند حدود المقاطع (تحقّق سمعي + تحليل طيفي للوصلات).
- [ ] الكلام مفهوم وواضح بعد إزالة الموسيقى (تقييم على عيّنات كلام-فوق-موسيقى).
- [ ] الفيديو منسوخ بلا إعادة ترميز؛ الصوت يُرمّز مرّة واحدة (AAC≥256k).
- [ ] لا انزياح صوت/صورة بعد الدمج.
- [ ] العملية في الخلفية مع تقدّم/إلغاء؛ foreground service يمنع القتل (Android).
- [ ] سلايدر القوة يغيّر النتيجة، والوقت المتوقّع معقول.

### المرحلة 7 — الصقل
- [ ] كل شاشة مُراجعة في (داكن/فاتح) × (ar/en).
- [ ] لا تجمّد للواجهة في أي عملية (مراقبة frame budget).
- [ ] لا تسريب ذاكرة في soak test (دفعة طويلة + إغلاق/فتح متكرّر).
- [ ] التطبيق يعمل بالكامل في وضع الطيران (تأكيد أوفلاين).

---

## بوّابات الجودة قبل أي إصدار
1. صفر فقدان/فساد في اختبارات الجراحية.
2. لا إعادة ترميز غير مقصودة (تحقّق آلي حيث أمكن).
3. أوفلاين بالكامل (لا أي نشاط شبكي — افحص بمراقب شبكة).
4. RTL + الثيمان + اللغتان على كل شاشة.
