# 08 — مكتبة المكوّنات (Components)

> كل مكوّن يستهلك tokens من `07-DESIGN-SYSTEM.md` فقط. لكل مكوّن: الحالات، القواعد، وسلوك RTL.

## مبادئ المكوّنات
- كل مكوّن له حالات صريحة: `default / pressed / disabled / loading / error` حسب نوعه.
- أهداف اللمس ≥ 44pt. هابتكس عند الأفعال.
- لا مكوّن يكتب لونًا/مسافة مباشرة.

---

## الأزرار (Buttons)
| النوع | المظهر | الاستخدام |
|---|---|---|
| Primary | تعبئة `--accent`، نص `--on-accent`, `radius-md` | الفعل الأساسي (واحد لكل شاشة غالبًا) |
| Secondary | حدّ `--border`، نص `--text` | فعل ثانوي |
| Tonal | خلفية `--accent-soft`، نص `--accent` | فعل بارز غير أساسي |
| Plain | نص فقط (`--accent` أو `--text`) | أفعال خفيفة/إلغاء |
| Destructive | نص/تعبئة `--danger` | حذف/استبدال جراحي فقط |
| Icon | أيقونة في هدف 44pt | أشرطة الأدوات |

الحالات: ضغط (تعتيم/تصغير 0.98 + هابتكس)، تعطيل (شفافية 0.4)، تحميل (spinner مكان النص).

---

## بطاقة الميديا (Media Card / Thumbnail)
- مربّع/نسبة أصلية داخل `radius-md`، خلفية `surface-sunken` أثناء التحميل (skeleton).
- شارات زاوية: نوع (فيديو/متحرك)، مدّة الفيديو، شارة «مضغوطة سابقًا» إن وُجدت.
- وضع التحديد: حلقة `--accent` بسماكة 2 + علامة ✓ دائرية.
- ضغطة = فتح (Hero)، ضغطة مطوّلة = دخول وضع التحديد المتعدّد.

---

## شريط التطبيق (App Bar)
- شفاف يتحوّل لـ `surface` مع ظل خفيف عند التمرير (large-title style: العنوان كبير ثم ينكمش).
- زر رجوع (ينعكس RTL) + عنوان + أفعال يمنى (≤ 2 ظاهرة، الباقي في قائمة).

---

## التنقّل (Navigation)
- **Tab Bar سفلي** (3–4 وجهات): المكتبة، الأدوات، المهام، الإعدادات. أيقونة + تسمية، الـ accent للنشط.
- على الشاشات العميقة: تنقّل هرمي مع زر رجوع.

---

## الأوراق السفلية (Bottom Sheets)
- `radius-xl` علوي، مقبض سحب، خلفية `surface`، تعتيم خلفي.
- تُستخدم لخيارات العملية (اختيار صيغة/جودة) وللإجراءات السياقية.
- قابلة للسحب للإغلاق + زر إغلاق صريح.

---

## عناصر الإدخال للقيم (Value Controls)
- **Segmented Control:** لاختيار صيغة/وضع (≤ 4 خيارات). المحدّد بخلفية `surface` مرتفعة فوق `surface-sunken`.
- **Slider:** للجودة/القوة. مقبض دائري، مسار `accent` للجزء المعبّأ. **يعرض القيمة الحيّة + الأثر** (مثلًا الوقت المتوقّع). ينعكس RTL.
- **Stepper / Numeric:** للأبعاد/الـ fps مع أزرار +/−.
- **Toggle/Switch:** أسلوب iOS، `accent` عند التفعيل.
- **Quality target chips:** «أعلى كفاءة (أبطأ) / متوازن / أعلى توافقية».

---

## التقدّم والحالة (Progress & Status)
- **Linear progress:** للمهام المحدّدة، يعرض % + المرحلة الوصفية + الوقت المتبقّي.
- **Indeterminate:** للمراحل غير المحدّدة (تحميل الموديل).
- **Skeleton:** للمصغّرات والقوائم أثناء التحميل.
- **Empty state:** أيقونة + عنوان + سطر إرشاد + (زر فعل اختياري). محايد وودود.
- **Error state:** أيقونة `--danger` + رسالة واضحة + زر إعادة المحاولة. لا لوم على المستخدم.

---

## شريحة المهمة (Task Row) — في شاشة المهام
- أيقونة نوع + اسم الملف + شريط تقدّم مصغّر + % + زر إلغاء.
- عند الاكتمال: ✓ + ملخّص (مثلًا «وُفّر 4.2MB») + زر «عرض».
- عند الفشل: أيقونة خطأ + سبب مختصر + إعادة محاولة (مع طمأنة أن الأصل سليم في العمليات الجراحية).

---

## نوافذ التأكيد (Dialogs)
- عنوان + شرح موجز + فعلان (إلغاء / تأكيد).
- **تأكيد مدمّر** (حذف/استبدال): زر التأكيد `--danger`، ونص يوضّح وجود سلة محذوفات/تراجع.

---

## مكوّنات خاصة بالمشروع

### Comparison Slider (ساحة المقارنة الجراحية)
- صورتان متراكبتان مع مقبض سحب عمودي يكشف «قبل/بعد».
- تكبير متزامن (pinch) للصورتين.
- أسفلها: شريط إحصاء (الحجم قبل/بعد، نسبة التوفير بـ `--success`، قائمة ✓ بالميتاداتا المحفوظة).
- على iOS: شارة المسار المختار (تعديل في المكان / حذف وإنشاء) مع تلميح أثره على «المضافة حديثًا».

### Savings Badge
- شارة `--success-soft` تعرض «−42% • 4.2MB» بأرقام tabular.

### Strength Slider (الفصل الصوتي)
- سلايدر بثلاث محطات + وضع «تلقائي» مميّز.
- يعرض الوقت المتوقّع الحيّ + بطاقة نصيحة صغيرة تحته.

### Trash Item (سلة المحذوفات)
- مصغّرة + اسم + تاريخ الحذف + عدّاد «يُحذف نهائيًا بعد N يوم» + زر «استعادة».

---

## قواعد الاتساق
- تباعد عمودي موحّد بين الأقسام (`space-6`).
- زر أساسي واحد بارز لكل شاشة.
- الأيقونات من نفس المجموعة والسماكة.
- كل مكوّن مُختبَر في (داكن/فاتح) × (ar/en).
